# Changelog

All notable changes to ReconCheck are documented here.

## 0.1.0 — 2026-09-22

- Added cross-platform `reconcheck analyze` command.
- Added automatic discovery of common COLMAP project layouts.
- Added image-only partial quality reports.
- Added sparse reconstruction diagnostics and point-quality attributes.
- Added optional dense-cloud and mesh visualization.
- Added per-image camera diagnostics and coverage inspection.
- Added portable JSON quality reports with versioned thresholds, findings, recommendations, image-health measurements, and provenance hashes.
- Added content-addressed platform-native cache without modifying source datasets.
- Bundled the React/Three.js viewer in the Python wheel.
